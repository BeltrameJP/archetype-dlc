# Agentic Workflows

This directory contains language-agnostic, step-by-step guides for various project types and tasks.

## 🚀 The 6-Phase Lifecycle

1.  **[01. Discovery & Ideation](01-discovery-and-ideation.md)**: Turning messy ideas into strict requirements.
2.  **[02. Architecture & Planning](02-architecture-and-planning.md)**: Translating requirements into an agent-actionable technical roadmap.
3.  **[03. Implementation Loop](03-implementation-loop.md)**: Infrastructure setup and atomic, self-correcting development.
4.  **[04. Validation & Review](04-validation-and-review.md)**: Peer-review, security scans, and PR generation.
5.  **[05. Integration & QA](05-integration-and-qa.md)**: Staging deployments and automated E2E verification.
6.  **[06. Release Orchestration](06-release-orchestration.md)**: Versioning, changelogs, and production deployment.

## 📝 Format

Each workflow should focus on the **behavior** and **logical steps** an agent should take, regardless of the programming language or framework being used.
