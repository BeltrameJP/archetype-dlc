# Best Practices

Universal guidelines for developing and managing projects using agentic workflows.

## 🔴 Priority Mandates

Before executing any workflow, you **MUST** read and internalize the [Core Mandates](00-core-mandates.md). These are the foundational rules for agent behavior in this repository.

## 🎯 Focus Areas

- **Core Mandates:** Foundational rules for agent behavior.
- **Feedback & Formatting:** Iterative refinement loops, YAML standards, and Mermaid visualizations.
- **Discovery & Epics:** Source synthesis loop and mandatory YAML structure for project Epics.
- **Build & Test Infrastructure:** Mandating user-guided discovery of build/test commands before planning or implementation.
- **TDD vs. Standard Implementation:** Dual behavioral modes for the implementation phase (Phase 03).
- **Validation & Review:** Code quality mandates, "no leetcoding," and impersonal feedback protocols.
- **Context Efficiency:** How to minimize token usage without losing critical intent.
- **Architectural Integrity:** Maintaining clean abstractions and following established patterns.
- **Safety & Security:** Protecting credentials and ensuring system stability.
- **Verification:** The importance of empirical testing and validation at every step.
