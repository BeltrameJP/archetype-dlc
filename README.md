# archetype-dlc

**archetype-dlc** is a language-agnostic repository of step-by-step agentic workflows and behavioral modes. Think of these as modular "Downloadable Content" (DLC) for your AI agents—giving them the structural blueprints and patterns they need to build projects with consistency, safety, and efficiency.

## 🚀 Concept

Agents perform best when they have a clear behavioral archetype to follow. This repository provides:
- **Workflows:** Step-by-step logic for specific project types.
- **Best Practices:** Language-free guidelines on context management, security, and architectural integrity.
- **Patterns:** Repeatable modes of behavior for complex engineering tasks.

## 📂 Structure

- `/workflows`: Modular step-by-step guides for project creation and management.
- `/best-practices`: Universal guidelines for agentic development.
